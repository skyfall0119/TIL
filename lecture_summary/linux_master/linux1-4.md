### 사용자 조회 명령어
- users: 시스템에 로그인한 사용자 정보 출력
- who : 현재 시스템에 로그인한 사용자들 조회. 간단한 정보 (사용자명, 터미널정보, 시각, IP)
- w : 현재 접속중인 사용자들의 정보를 나타냄
    - 보여주는 서버정보
        - 서버 시스템 시각
        - 부팅 이후 경과 시간
        - 접속 사용자 수
        - 사용자간 CPU 사용률
    - 보여주는 사용자 정보
        - 사용자 명 (USER)
        - 터미널 정보 (TTY)
        - 접속 IP (FROM)
        - 로그인 시각 (LOGIN@)
        - CPU 사용량 (IDLE, JCPU, PCPU)
        - 현재 사용 명령어 (WHAT)
- id : 사용자 계정의 uid, gid, gropu 을 확인하는 명령어
- groups: 사용자 계정이 속한 그룹을 확인하는 명령어
    - /etc/group

### 디렉토리 관련 명령어
- pwd : 현재 작업 디렉토리 확인
- cd : 디렉토리 이동
- mkdir : 디렉토리 생성
- rmdir : 디렉토리 삭제
- ls : 파일 목록
    - a 히든 파일 포함
    - l 자세히 나타냄
    - r 알파벳 역순
    - R 하위 경로와 그 안의 파일 표시
- cp 파일 또는 디렉토리 복사
    - b 복사대상파일이 존재하는 경우 백업파일 생성
    - f 복사대상파일 존재할 경우 덮어씌움
    - i 복사대상파일이 존재하는 경우 덮어쓸지 물음
    - r 하위 디렉토리까지 복사
    - v cp 명령어를 수행하면서 복사 진행상태 출력
    - p 파일, 디렉토리 복사할때 대상의 소유자(계정), 그룹, 권한 등의 정보까지 복사
- rm 파일 , 디렉토리 삭제
    - f 강제 삭제
    - i 삭제할지 물음
    - r 하위 디렉토리까지 모두 삭제
- mv 파일 또는 디렉토리 이동
    - b 대상 파일이 지워지는 것에 대비해 백업파일 생성
    - f 강제로 이동/변경
    - v 파일이 옮겨지는 과정이 상세히 표시
- touch 파일 크기가 0 파이트인 빈 파일이 생성
    - 서버의 현재 시간으로 퍼일의 최근 사용시간, 수정시간 등 타임스탬프 변경
    - a 접근시간 변경
    - m 수정시간 변경
    - c 시스템 현재 시간으로 파일 시간정보 수정
    - r 파일1의 시간정보를 파일2에 동일하게 적용

### 파일 관련 명령어
- file 파일의 종류 및 파일 속성값을 나타냄
    - b 파일명은 출력하지 않고 유형만 표시
    - f 파일 목록에 지정한 파일들에 대해서만 명령을 실행
    - z 압축된 파일의 내용출력
    - i MIME 타입문자로 출력

- find : 주어진 조건의 파일을 찾아 해당 경로를 표시
    - name: 이름을 기준으로 파일 검색
    - user: user 의 파일이나 디렉토리 검색
    - perm : 지정된 권한의 파일 검색
    - type : 파일 유형에 따라 파일 검색
    - exec : 검색된 파일에 수행할 명령어 지정
