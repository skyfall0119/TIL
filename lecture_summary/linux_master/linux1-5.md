### 텍스트파일 관련 명령어
- cat : 파일 내용 출력
    - n 줄번호 붙여서 출력 (빈 라인 포함)
    - b 줄번호 붙여서 출력 (비어있지 않은 라인만 )
- head/tail : 파일 앞부분/뒷부분 출력
    - 숫자
- more : 파일을 화면 단위로 끊어서 출력
    - 숫자 : 한 페이지에 표시되는 라인 수
    - *엔터 : 한 라인씩. 스페이스파: 한 화면씩 q: 빠져나옴*
- less : 기능적으로 more 화면을 확장
    - 텍스트 파일을 한번에 한 화면씩 출력
    - :q 중지
- **grep** : 특정 문자열 / 정규표현식의 단어를 찾는다
    - n 라인수 출력
    - i 대소문자 무시
    - F 패턴이 string 임
    - B (before) / A (after) / C (위아래)
- wc : word count 파일의 라인수, 단어수, 알파벳 수
    - l : 전체 라인수
    - w : 전체 단어수
    - c : 전체 알파벳수
- sort : 명령어 결과 또는 문서 내용을 정렬하여 출력
    - r 역순으로 정렬
    - t 대소문자 구분 X
- cut : 파일에서 특정 필드 추출
    - b 바이트 기준 잘라내기
    - c 캐릭터 기준으로 잘라냄
    - d 지정한 문자를 구분자로 사용 (기본 TAB)
    - f 필드를 기준으로 
    - cut -d ':' -f 1 /etc/passwd (: 를 기준으로 자르고 그 필드의 1번째)
- split : 한 큰 파일을 여러개의 파일로 분리
    - b 바이트 단위로 분리
    - l 라인수 단위로 분리

### 파일 비교 명령어
- diff : 두개 파일 내용을 행 단위로 비교해 다른 부분을 출력
- cmp : 두 파일을 바이트 단위로 비교하여 출력
    - b 바이트 출력
    - l 두 파일간 다른 문자 위치와 문자를 출력
- comm : 두 파일을 줄 단위로 비교하여 출력
    - 1 파일 1에만 있는 내용 제외
    - 2 파일 2에만 있는 내용 제외
    - 3 두파일 공통 내용 제외

### 리다이렉션 
- 표준 출력 덮어쓰기 >
    - cat ttest > newfile
- 표준 출력 추가 >>
    - cat newdata >> log
- 표준입력 <
    - 파일로부터 입력받음

### 정규표현식
- ^ : 라인 첫글자
    - ^a  : a 로 시작하는 문자
- $ : 라인 끝글자
    - a$  : a로 끝나는 문자
- . : 한글자
    - a..b : a b 사이 2개 문자
- \* : 이전 글자나 정규식이 0회 이상 반복
    - ab*  : b가 0번이상 반복
- [] 대체글자 목록을 나열. 
    - [abc]d  : abc 중 어떤 한글자라도 반드시 있는 단어 (ad, bd, cd)
- [^] 대체못할글자 목록을 나열
    - [^abc]d : abc중 어떤 글자도 포함하지 않는 단어
- \+ 이전 글자나 정규식이1회 이상 반복
    - ab+c : b가 1회이상 반복
- ? 이전 글자나 정규식이 없거나 1회만 존재
    - ab?c : b가 없거나 한번 존재
- () 부분 정규 표현식의 시작과 끝 표시
    - a(bc)*
- | 로 구분된 단어들중 최소 하나 존재
    - a(b|c) b 또는 C 가 최소 1개 존재
- {m,n} {} 기호 바로 이전 글자나 정규표현식이 m개이상 n 개 이하 반복
    - a{1,3}b
