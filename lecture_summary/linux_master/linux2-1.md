# 운영체제

- 인간과 컴퓨터 사이의 인터페이스
- 자원을 효율적으로 관리, 운영

## 자원관리
#### 메모리 관리
- 메인 메모리 관리 (프로세서가 직접 주소로 지정할수 있는 유일한 메모리)
- 어느부분을 사용, 누가사용할지
- 메모리 할당/회수
- 보조기억장치 관리: 메인메모리는 제한적임. 프로그램을 보조기억장치에 저장
    - 빈 여유공간 관리
    - 새로운 파일 작성시 장소 할당
    - 접근 요청 스케줄링
    - 파일 생성/삭제

#### 프로세스 관리
- 실행중인 프로그램
- 운영체제프로세스 / 사용자 프로세스
- 프로세서를 분할 사용하여 병행 수행 가능
- 프로세스 관리를 위한 운영체제 기능
    - 프로세스,스레드 스케줄링
    - 사용자 프로세스와 시스템 프로세스 생성/제거
    - 프로세스 중지/재수행
    - 프로세스 동기화 방법 제공
    - 프로세스 통신 방법 제공
    - 교착 상태 방지 방법 제공


#### 주변장치 관리
- 특수 프로그램인 장치 드라이브를 사용하여 입출력 장치와 상호작용
- 장치 드라이버는 특정 하드웨어 장치와 통신할 수 있는 인터페이스 제공 -> 특정 하드웨어에 종속됨
- 관리를 위한 운영체제 기능
    - 임시저장 시스템 기능 제공 (buffer-caching)
    - 일반 장치용 드라이버 인터페이스 제공
    - 특정 장치 드라이버 제공

#### 자원관리
##### 1. 파일 관리
- 입출력 파일의 위치, 저장, 검색 관리
- 다양한 형태로 파일 저장 가능
- 데이터의 효율적 사용을 위해 단일화된 저장 형태 제공
- 디렉토리로 구성하고 접근 제어
- 운영체제 기능
    - 파일 생성/삭제
    - 디렉터리 생성/삭제
    - 보조기억장치 파일 맵핑
    - 안전한 저장장치에 파일 저장

##### 2. 시스템 관리
- 시스템보호 (권한부여)
    - 컴퓨터 자원에서 프로그램, 프로세스, 사용자의 접근 제어 방법
    - 운영체제는 파일 사용권한 부여, 데이터 암호화 등 서비스 제공, 데이터와 시스템 보안
    - 컴퓨터 시스템에서는 여러 프로세스 동시 실행 가능하므로 상호보호해야 함
    - 네트워크로 파일 공유 사이트에 접속 시 다른 사용자의 프로그램에서 보호
- 네트워킹 (통신)
    - 다양한 방법으로 구성된 네트워크 이용, 완전 접속과 부분 접속 방법으로 연결
    - 연결된 프로세서가 통신을 할때는 경로 설정, 접속정책, 충돌, 보안 등 고려
- 명령어 해석기 (command interpreter)
    - shell
    - 대화형으로 입력한 명령어를 이해하고 실행하는 사용자와 운영체제의 인터페이스
    - 인터페이스 역할을 할뿐 운영체제는 아님
    - 커널과 분리하는 것이 좋음 (명령 해석기의 인터페이스 변경 가능)
        - 분리하지 않으면 사용자가 커널의 코드를 변경할 수 없어 인터페이스 변경 불가

### 운영체제 역할
- 사용자 / 컴퓨터 시스템간의 인터페이스 정의
- 사용자들간의 하드웨어 공동사용
- 여러 사용자간의 자원 공유
- 자원 스케줄링
- 입출력 보조 역할
- 에러 처리
- 사용자들간 간섭 방지
- 자원 사용량 계산
- 병렬 수행 편의 제공
- 데이터 보안, 통신 네트워크 관리

### 목적
- 사용의 편리성
- 시스템 성능 향상
    - 처리능력 (throughput) : 일정 단위 시간동안 처리하는 작업 양
    - 응답시간 (turn around time) : 한 작업을 처리할때의 경과시간
    - 사용의 용이성 (availability) : 적절한 때에 얼마나 빨리 사용가능한가
    - 신뢰도 (reliability) : 올바로 작동함?


### 구성
- 1. 제어 프로그램
    - 감시 (supervisor)
    - 데이터관리 (data management)
    - 작업제어 (job control)

- 2. 처리 프로그램
    - 언어번역 (language translator)
    - 서비스 (service)
    - 문제 (problem)


### 구조
- 커널 
    - 인터럽트 처리기. 디스패쳐, 프로세서 동기를 위한 기능 지원.
    - H/W 와 밀접하게 관련
    - 기억장치 관리기
    - 입출력 시스템
    - 파일 관리기
    - 단기 스케줄러 (시스템 내 활성 큐 관리, cpu 관리, HW 와 무관)
    - 자원관리기: CPU 를 제외한 다른 자원들 관리
    - 장기 스케줄러 (프로세서의 생성, 소멸, 제어 담당)
    - 명령어 해석기: 사용자와 직접 대화. (shell)
