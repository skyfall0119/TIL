## OSI 7
- Open Systems Interconnection Reference Model
- 기종간 상호통신을 위해 국제표준화기구 (ISO) 에서 컴퓨터 네트워크 프로토콜 디자인과 통신 계층을 구성하여 개발한 네트워크 모델
- 개념적 모델. 실제 네트워크 구현시 참조모델
- 각 계층은 하위 계층이 제공하는 서비스를 이용. 상위 계층에게 서비스 제공
- 상위에서 하위로 데이터를 전달할때 헤더와 트레일러를 추가하여 데이터 캡슐화
- 수신할 경우 헤더와 트레일러를 제거하고 분석하여 상위로 전달하는 역캡슐화 진행
- 물리 - 데이터 링크 - 네트워크 - 전송 - 세션 - 프레젠테이션 - 응용

#### 1. 물리계층
- 전기적, 물리적 연결 담당
- 케이블 종류, 무선 주파수 링크
- 핀배치, 전압, 물리 요건 등
- 비트단위 전송
- 허브, 리피터

#### 2. 데이터링크 
- 프레임 단위로 데이터 전송
- 식별가능하도록 MAC(Medium access control) 주소
- 수신 노드의 수신 속도에 맞추기 위해 송신 노드가 데이터를 느리게 보내는 흐름제어 수행 (정지대기, 슬라이딩 윈도우)
- 회선 제어 기능 제공
- 오류제어 기능 제공
- 수신측 오류 감지시 NAK 반환. 전송측에서 재전송 (ARQ= Automatic Repeat Request)
    - 정지대기(Stop-and-wait) ARQ, Go-Back-N ARQ, SR(Selectvie repeat) ARQ
- 재전송 없이 직접 오류 정정 (FFE = Forward Error Control)
    - 매개접근제어 계층, 논리연결제어 계층 
- 브리지, 스위치

#### 3. 네트워크 계층
- 2개의 노드가 여러 네트워크를 거쳐 연결되어 있음
- 송신/수신 사이의 경로설정 (라우팅 기능)
- 패킷 단위 데이터 분할 전송
- 논리적 주소 설정
- 혼잡제어, 패킷분할/병합, 인터네트워킹 기능 제공
- 라우터

#### 4. 전송 계층
- 송신 수신 간 연결 제공
- 주소, 포트 지정. 연결제어, 오류 복구, 흐름 제어
- 세그먼트 단위 데이터 전송
- 커널의 시스템 콜을 통하여 상위 계층에게 기능 제공
- TCP/IP

#### 5. 세션 계층
- 메세지 단위로 데이터 전송
- 세션 설정, 유지
- 동기 기능
    - 통신 양단에서 논리적으로 상호 데이터 전송이 잘되었을때 동기점 설정
    - 전송 오류 발생시 동기점 후의 데이터만 복구
- 대화 기능
    - 데이터 전송 기능
    - 신뢰성 있는 전송을 위해 순차적으로 동기점을 부여하면서 단계적 데이터 전송
    
#### 6. 표현 계층
- 다양한 표현 방식 제공
- 데이터 암호화, 해독기능, 압축, 압축해제 기능

#### 7. 응용계층
- 사용자에게 편리한 응용 환경을 제공하는 기능
- 전자우편, 웹서비스, 원격접속, 파일전송 등
- 가상터미널 등

## 네트워크 장비
#### 네트워크 카드
- 컴퓨터를 네트워크에 연결 가능하게 하는 네트워크 장치
- NIC (Network Interface Controller) / Network Adapter
- OSI 계층 중 1,2 기능 수행. MAC 주소 (고유주소) 지정 기능 제공
- 마더보드에 온보드 되어 제공되는 경우가 많음

#### 케이블
- 단말 사이 송수신 되는 자료 연결
- 전화선, 동축케이블, 광섬유 케이블

#### 허브
- 다양한 기기로부터 전기신호를 받아 그 신호를 증폭시켜 다른 기기들로 뿌려줌
- 멀티포트 리피터

#### 리피터
- 데이터가 전송될때 감쇄 현상으로 신호가 약해지는걸 다시 증폭 재생해줌 (1계층 장비)

#### 브리지
- 여러개의 네트워크 세그먼트를 연결하기 위해 데이터 프레임의 MAC 주소를 보고 해당 포트로 포워딩하는 장비 (2 계층)

#### 라우터
- 독립된 네트워크를 서로 연결
- 송신측 패킷을 목적지까지 전달하기 위해 가장 효과적인 경로를 찾아 데이터를 포워딩 (3계층)

#### 게이트웨이
- 서로다른 프로토콜이나 통신망을 사용하는 네트워크를 연결하기 위해 프로토콜의 변환기능을 제공하는 장비 (전송, 응용 계층 장비)

## 데이터 통신 기본
- 토폴로지
    - 물리적/논리적 네트워크 배치 방식
    - 링크와 연결된 노드간의 관계를 기하학적으로 표현
    - 버스형, 메시형, 링형, 스타형, 트리형

- 버스형
    - 공통 배선을 모든 노드가 공유
    - 근거리 (LAN) 일반적 방식
    - 설치 간단 비용 최소화
    - 한노드 전송 -> 모든 노드 수신
    - 연결에 필요한 링크의 길이 제한
    - 버스 고장시 네트워크 전체 동작 X
    - 링크 길이가 길어지면 신호 감쇠
    - 두 노드가 동시에 신호전송 시 충돌

- 스타형
    - 각 노드는 중앙 제어 노드와 점대점 방식으로 연결
    - 중앙 제어 노드가 통신상 제어에 대한 권한과 책임
    - 모든 전송은 중앙 허브를 통하여 중계
    - 설치 비용 저렴
    - 고장 수리 쉽고 증설 이전 쉬움
    - 확장성
    - 허브 문제시 전체가 통신불능
    - 데이터양 증가시 지연시간 증가

- 링형
    - 자신의 양쪽 노드와 점대점 방식
    - 한방향으로만 링을따라 목적지로
    - 링크 길이를 줄일수 있음
    - 설치/재구성 쉬움
    - 링 제어 절차 복잡
    - 하나의 노드 문제시 네트워크 전체 통신 불능 (이중링으로 해결)
    - 새로운 노드 추가시 물리적 링 절단 후 노드 추가

- 메시형
    - 각 노드간 점대점
    - 신뢰성
    - 고장 발견 쉬움
    - 한 노드 문제가 네트워크에 주는 영향 최소화
    - 구축 비용 많이듦
    - 설치,설정 과정이 오래 걸림

- 트리형
    - 스타형 변형
    - 중앙이 중계기 기능을 갖춘 능동적 허브
    - 중앙허브-2차허브-노드
    - 중앙허브에 많은 노드 연결 가능
    - 중앙허브에 병목 현상 가능
    - 중앙 허브 문제시 네트워크 마비/분할

#### 통신방식
- 이더넷
    - LAN, MAN, WAN 
    - IEEE 802.3 표준화
    - 반이중통신 지원 
    - CSMA/CD
    - 10Mbps, 100Mbps, 1Gbps

- 토큰링
    - 토큰을 획득한 노드만 데이터 전송가능
    - IEEE 802.5 표준화
    - 4Mbps, 16Mbps 수준
    - 스위치 이더넷 보급 이후 쇠퇴

- FDDI
    - Fiber Distributed data interface
    - lan 들을 연결하는 백본망 구섷
    - 주 링, 부 링으로 구성된 이중 링에 스테이션 연결
    - 100Mbps 대역폭
    - 최대 1000개의 스테이션 연결 가능
    - 최대 전송길이 100~200km (단일모드), 2km (다중모드)
    - 광섬유 사용. 토큰 패싱 기술 활용하는 100Mbps Lan/Man 기술


#### 교환 방식
- 회선 교환방식
    - 전화연결
    - 발신자/수신자간 독립적 폐쇄적인 통신연결

- 패킷 교환 방식
    - 작은 블록 패킷으로 데이터 전송
    - 데이터그램
        - 데이터를 전송하기 전 논리적 연결 설정 X
        - 패킷은 독립적으로 전송
        - 하나의 메세지에서 분할된 여러 패킷은 다른 경로로 전송될 수 있음 (비연결 지향형)
        - 전송순서와 도착순서가 다를수 있음
    - 가상회선 패킷 교환 방식
        - 데이터 전송 전 논리적 연결 설정 (연결 지향형)
        - 패킷에 가상 식별번호 (VCI) 포함
        - 전송된 순서대로 도착

#### 패킷 교환 기술
- X.25
    - 초기 전화망 이용시 통신회사들의 독자적인 프로토콜 호환성 이슈
    - ITU-T 에 의해 표준화됨
    - DTE, DCE 간 점대점 인터페이스 정의
    - 연결 지향 프로토콜. 가상 회선 기능 제공
    - 1,2,3 계층
- 프레임 릴레이
    - LAN 및 광 케이블의 사용 후 고속망의 필요에 따라 개발된 패킷 교환 기술
    - 가상 회선 기능 제공. 통계적 다중화 기능을 제공하여 효율적인 대역폭 사용 제공
    - 오류 제어 기능 단순화. 
    - 오류 복구 기능을 상위 프로토콜에 일임
    - 1,2계층
- 셀 릴레이
    - ATM (비동기 전송 모드) 기술 사용
    - 프레임 릴레이보다 고속 데이터 통신서비스 제공
    - 모든 정보를 48바이트씩 구분하여 블록 생성, 5바이트 헤더
    - 가상 경로, 가상 채널 설정
    - 56kbit/s ~ 초당 수 기가바이트
    - 흐름제어, 오류제어 기능 X
    - 1,2 계층
