
## 명령어
- alias 
    - 명령어 별칭. 
    - ex) alias l='ls -CF'
    - 등록: alias p='pwd'
    - 제거: unalias p

- which
    - 명령어 경로 확인
    - which docker -> /usr/bin/docker

- man
    - 리눅스 명령어 매뉴얼 제공
    - -h 사용법 출력 (help)

- info
    - 리눅스 명령어 사용방법, 옵션 등을 나타냄
    - info which

- whatis
    - 명령어 설명
    - whatis ls

- whereis
    - 찾는 명령어의 실행파일 절대경로 소스. 설정파일 매뉴얼 페이지 출력
    - whereis which

- apropos 
    - man 페이지 설정에서 지정한 키워드를 포함하고 있는 명령어
