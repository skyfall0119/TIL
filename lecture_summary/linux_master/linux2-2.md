## 주요개념
- GNU 프로젝트
    - GNU : GNU is Not Unix 
    - 유닉스 호환 자유 소프트웨어들을 개발
    - gcc, emacs, bash, gnome

- GPL (General public license)
    - FSF 에 의해 만들어진 특별한 오픈소스 라이선스 (copyleft)
    - fsf : free software foundation 리차드 스톨만
    - 배포/복사/소스코드 수정 가능
    - GPL 프로그램 수정해서 만든 프로그램 또한 GPL
    - 다른 소프트웨어와의 완전한 통합은 해당 소프트웨어가 GPL 을 수용한다는 조건에서만 가능
    - 독점 소프트웨어와 결합시 해당 영역 소스 공개해야 함
- LGPL (Lesser General Public License)
    - GPL 조건 완화 라이센스
    - LGPL 프로그램 소스코드를 이용한 프로그램 판매/배포시 프로그램 소스 공개 의무 없음 (명시만 하면 됨)
    - 수정한 경우 전체 코드 공개해야 함
- BSD (Berkeley Software Distribution) 
    - BSD 계열 소프트웨어에 적용되는 오픈소스 라이선스
    - 소스코드 공개의무 없음
    - 저작권자 표기

## RAID
- 여러가지 디스크를 하나의 디스크처럼 사용하는 방법
- RAID 0
    - 스트라이핑 기능 (분배기록) 사용.
    - 빠른 I/O 성능
    - 고장 대비 능력 X
- RAID 1
    - 두개 이상의 디스크를 미러링을 통해 하나의 디스크처럼 사용
- RAID 2
    - ECC (에러 검출 기능) 탑재
- RAID 3
    - 하나의 디스크를 에러검출을 위한 패리티 정보 저장용으로 사용
    - 나머지 디스크에 데이터를 균등하게 분산 저장
- RAID 4
    - RAID 3 과 같지만 블록 단위로 분산 저장
- RAID 5
    - 하나의 디스크에 피리티 정보를 저장하지 않고 분산 저장
    - 회전식 패리티 어레이
- RAID 6
    - 하나의 패리티 정보를 두개의 디스크에 분산 저장
    - 쓰기 능력 저하
    - 고장 대비능력 높음
- RAID 7
    - 실시간 운영체계 사용
- RAID 0+1
    - 4개 이상 디스크
    - 2개씩 스트라이핑 (RAID 0)
    - 미러링으로 결합 (RAID 1)
- RAID 1+0
    - 두개의 디스크를 미러링 (RAID1)
    - 스트라이핑으로 결합 (RAID0)


## 리눅스 구조
- 리눅스 부트로더 (LILO/GRUB)
    - 부트로더: OS 가 시동되기 전 미리 실행되면서 커널이 올바르게 시동되기 위해 필요한 모든 관련 작업을 마무리하고 최종적으로 OS 를 시동하기 위한 프로그램
    - LILO (LInux Loader)
        - 리눅스 배포판의 표준 부트로더
        - 대화형 명령어 인터페이스 X
        - 네트워크 부팅 지원 X
    - GRUB
        - 리눅스, vista, dos 및 기타 os 에서 사용
        - 새로운 기본 부트로더
        - 대화형 명령어 인터페이스
        - 네트워크 부팅 지원
        - 문제 있을시 grub-install 명령어로 복구

## shell
    - 명령줄 인터페이스 방식 (CLI)
    - 그래픽 유저 인터페이스 방식 (GUI)
    - window, macOS 는 GUI 방식 쉘
    - 전통적으로 리눅스 쉘 = CLI
    - 리눅스 기본 쉘 bash Shell
    - 쉘 설정/확인
        - 환경변수 SHELL 을 통해 확인 가능 $echo $shell
        - /bin/bash
        - 지원하는 쉘 목록 확인 /etc/shells
        - 쉘 변경 $chsh -s 
        - /etc/passwd 7번째 필드에 사용자의 셀 확인 가능
- 환경변수 설정확인
    - HOSTNAME 시스템 호스트명
    - OSTYPE 운영체제 유형 정보
    - DISPLAY 윈도우 트래픽을 처리할 X디스플레이 서버 위치
    - PATH 실행파일이 위치한 디렉터리 집합
    - LANG 셀 사용시 기본 지원 언어
    - SHELL
        - PS1 기본 프롬프트 표시명
        - PS2 하나의 명령어를 여러줄로 입력할때 표시하는 프롬프트 표시명
        - SHELL 로그인한 사용자 셀
        - HISTFILE 히스토리 정보 파일 경로
        - HISTFILESIZE 히스토리 파일 크기
        - HISTSIZE 히스토리 파일 명령어 개수
    - 사용자정보
        - UID UID
        - USER 계정명
        - HOME 홈디렉토리
        - PWD 현재 작업 디렉토리 경로
    - 응용 프로그램
        - TERM 사용자 터미널 종류
        - MAIL 수신메일 저장 경로

## Process
- 실행중인 프로그램
- 메모리에 적재되어 자원 할당을 받아 작업을 수행하는 단위
- 독립된 메모리 영역 (코드, 데이터, 스택, 힙 등)
- 상태: new, ready, running, waiting, terminated
- 자원관리, 보호, 상태변화

#### 유형
- 최상위 프로세스
    - 시스템이 시작될때 가장먼저 생성
    - init / systemd
    - 모든 다른 프로세스는 자식프로세스로 생성됨 (트리구조)
    - 시스템 전체의 프로세스 관리 자원할당 담당
- 부모프로세스 PPID / 자식프로세스 PID
    - 프로세스 A 가 특정 실행파일을 실행하여 프로세스 B 가 생성되었을떄
- 고아 프로세스
    - 부모가 자식보다 먼저 종료
    - init이 새로운 부모로 설정됨
    - 고아가 종료되면 init 이 종료상태를 수집해 자원 회수
    - 자동으로 처리됨
- 좀비 프로세스
    - 자식이 종료된 후에도 부모가 종료상태를 회수하지 않음
    - PID, 종료상태 등 최소한의 정보만 남아있음
    - 시스템 자원 소모
    - 부모가 wait 계열 함수로 자식 상태를 회수하여 제거
- 데몬
    - 운영체제에서 사용자가 직접 제어하지 않고 백그라운드에서 동작하는 프로세스
    - 시스템 부팅시 자동 시작
    - 웹서버, 프린터 서버
    - 이름 끝에 d 가 붙음 (httpd, crond)
    - 윈도우 service와 유사

        - $exec ls -l
